## About

I am a senior system administrator who works on identity, endpoint management, and Windows infrastructure. I write PowerShell tools that turn repetitive admin work into repeatable, documented steps.

My focus areas:

* Microsoft Intune reporting, remediation, and device operations
* Microsoft 365 and Entra ID administration through Graph
* Active Directory inventory, health checks, and cleanup
* WPF GUIs for helpdesk and operations teams
* Enterprise standards that keep generated scripts consistent and reviewable
